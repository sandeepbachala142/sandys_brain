## The Core Setup Hierarchy

```
Step 1: Identify day type from profile shape
        D = balance → fade extremes (LAF/LBF)
        P = bullish → only LBF longs
        B = double dist → LVN model in the gap
        Trend = LVN model in direction of trend

Step 2: Mark levels premarket (OVH/OVL, VAH/VAL, POC, LVNs)

Step 3: Wait for price to reach a level

Step 4: Read the tape at the level
        Big prints? → who's aggressive?
        Delta heavy one direction but price not moving? → absorption
        Delta flipping? → trapped pool forming

Step 5: Pick the setup
        Sweep + fail to extend + reclaim → LAF/LBF
        Cluster breakout + shallow pullback + defense → LVN Model
        Resistance turned support with absorption → continuation

Step 6: Enter with orderflow confirmation
        Small first, add on confirmation
        Stop at invalidation
        Target 1 = POC/midpoint, Target 2 = next session level

Step 7: Manage
        No acceleration after break → cut
        Move SL to BE at Target 1
        Take profits quicker in chop
```
