# Script Story Framework

Every great video follows this 5-step structure. Before writing any script, fill this out first. If you can't answer all 5, the idea isn't ready yet.

---

## The 5 Steps

| Step | Question to Answer |
|------|--------------------|
| **1. Situation** | What is the starting point? Who is the character and where are they? |
| **2. Desire** | What does the character want? What's the goal or dream? |
| **3. Conflict** | What gets in the way? What makes it hard? |
| **4. Change** | What happens that shifts something? The turning point. |
| **5. Result** | How does it end? What did the character gain, lose, or learn? |

## Example — The Stranger Who Changed My Life

| Step | |
|------|-|
| **Situation** | Worst student in college, 2 backlogs, campus interviews starting |
| **Desire** | Get the TCS job — the only company that allows backlogs |
| **Conflict** | Zero coding knowledge, technical round coming up |
| **Change** | A stranger teaches Java for 8 hours straight without a break |
| **Result** | Got selected. Never saw that stranger again. |

---

## Note on Value/Tips Videos

For videos without an external story (like how-to or advice content), make **yourself** the character:

- **Situation** = Where you were before you figured it out
- **Desire** = What you were trying to achieve
- **Conflict** = What was stopping you or what most people get wrong
- **Change** = The insight, framework, or moment that shifted things
- **Result** = Where you are now / what the viewer can achieve

---

## The Test

Before scripting, ask: *"Can I fill in all 5 steps clearly?"*

- If yes → start writing
- If no → the idea needs more development
