# Journals

This is Sandy's running life journal. Raw, unfiltered, real.

## How it works

1. **Journal freely** — open a new note, name it the date (e.g. `2026-05-02.md`), 
   use the template or just free-write. No rules, no pressure.

2. **Ask Claude for video ideas** — after journaling (or anytime), say: 
   *"Read my recent journals and give me video ideas."* Claude will scan 
   the entries and pull real ideas from your actual life.

3. **Ideas flow into Sandy Creates** — any idea worth developing moves to 
   `03 Projects/Sandy Creates/00 Ideas/`
